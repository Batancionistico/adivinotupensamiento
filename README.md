# Adivina Tu Pensamiento

Una página web interactiva donde "adivino" el número que estás pensando.  
Solo elige un número del 1 al 10 y observa cómo realizo complejos cálculos para descubrirlo.

## Página web
Puedes visitarla aquí:

https://Batancionistico.github.io/adivinotupensamiento/

## Características

- Animaciones estilo Matrix
- Mensajes aleatorios
- Tiempo de cálculo dinámico
- Resultado sorpresa con datos falsos
- Mensaje oculto cifrado

## Propósito
Este sitio es una página broma con fines de entretenimiento.
